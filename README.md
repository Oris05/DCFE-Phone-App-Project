
# What the Project Is
This project is a simple Node.js and Express web application that connects to a MySQL database and allows users to manage mobile phone entries by adding new phones, viewing all phones, filtering phones by brand, and opening individual product pages, with EJS used for rendering and all data stored in a MySQL table.

# How to Run It
To run the project, install Node.js and MySQL, clone the repository, run `npm install`, set up a MySQL database and import the required table structure, update the database connection details in the code, start the server with `node index.js`, and open `http://localhost:3000` in your browser to use the application.
